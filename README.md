# Portfolio

Personal portfolio of Willian David Correa. Plain HTML and CSS, no build step and no external requests.

## Run it locally

Open `index.html` in a browser.

## Edit

- Text and projects: `index.html`
- Colors and layout: `assets/style.css` (the Valle Perenne palette is defined at the top, for day and night)
- Theme toggle: `assets/script.js`

Before publishing, replace the two placeholders in `index.html`: `__LINKEDIN_URL__` and `__EMAIL__`.

## Deploy

The site deploys on AWS Amplify Hosting from the `main` branch. `amplify.yml` publishes `index.html` and `assets/`.

## Fonts

Self-hosted from Fontsource, both under the SIL Open Font License 1.1:
Young Serif and Atkinson Hyperlegible Next. Licenses are in `assets/fonts/`.
